# androidstudiowinhelper

StudioWinSetup is a Windows-focused installation assistant for Android Studio. It helps users quickly install and configure Android Studio, JDK, SDK, environment variables, and common development dependencies. With step-by-step guidance, environment checks, and troubleshooting hints, the project simplifies Android development environment setup for beginners, classrooms, and new developer machines.
